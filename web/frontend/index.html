Help Peer: hand off large files, end-to-end encrypted

Send large files to a person or an agent with a one-time code: model weights, datasets, tarballs, anything except images, video and audio. The sender can go offline straight away; the files wait, end-to-end encrypted, for up to 24 hours.

  • Zero-knowledge: files are encrypted before they leave your machine.
  • Built for agents: a CLI and Python SDK with JSON output and resumable, verified downloads.
  • Resilient: each piece is split into 12 shards across storage nodes; any 8 rebuild it.
